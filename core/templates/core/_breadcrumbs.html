{% comment %} D-12 — partial reutilizável de trilha de navegação (breadcrumbs). Contrato: a view que inclui este partial passa `trilha`, uma lista de dicts na forma `{"rotulo": str, "url": str|None}`. O ÚLTIMO item da lista é sempre a página atual e NUNCA carrega `url` (renderiza como texto puro, sem link) — os demais itens carregam `url` e renderizam como ``. A trilha é montada pela view SEMPRE a partir de dados já presentes no contexto — este partial NUNCA faz consulta, NUNCA usa `{% load %}` de templatetag com ORM por trás. Nota deliberada: o kernel desta fase entrega ZERO template tags customizadas por decisão — D-12 veta templatetag com ORM por trás e a trilha vem pronta da view. O item "template tags" do requisito CORE-04 é atendido intencionalmente sem tags (não é uma lacuna).
