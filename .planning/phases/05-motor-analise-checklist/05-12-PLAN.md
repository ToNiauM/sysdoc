<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| `dados_consolidados.json` → DOCX assinável | conteúdo revisado por humano vira minuta oficial |
| template `.docx` de `referencias/` → processo de geração | arquivo ZIP de origem externa é aberto e reescrito |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-05-40 | Tampering | injeção de XML pelo conteúdo do JSON quebrando o DOCX ou inserindo marcação | mitigate | `render_docx_template` já aplica `xml_escape` a todos os valores; a `tabela_itens` é montada com o mesmo escape antes de virar parágrafos |
| T-05-41 | Elevation of Privilege | template `.docx` malicioso com macro ou entrada de caminho absoluto no ZIP | mitigate | a geração copia entradas do ZIP de origem sem executar nada; recusar template cujo `infolist` contenha caminho absoluto ou `..`; o template vem de pasta controlada pelo próprio usuário |
| T-05-42 | Repudiation | minuta automática confundida com documento final | mitigate | a saída é minuta para assinatura por decisão de produto (RF10); a mensagem final do comando declara que a revisão humana ocorre no JSON/HTML antes do `create` |
</threat_model>
