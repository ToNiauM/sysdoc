O `estilo` nunca vem de dado externo — só das constantes acima.
- `_cabecalho_peca(numero: int, peca: str, sei: str) -> str` — `"{numero}) {rótulo}"`, acrescido de `" (SEI {sei})"` somente quando `sei.strip()` não está em `SEI_AUSENTE`.

- `_texto_referencia_cruzada(letra: str, numero_secao: int) -> str` — `f'Vide apontamento constante na alínea "{letra}" do item {numero_secao} do presente documento.'`, precedido do prefixo de seção quando houver, exatamente como as linhas 33-39 do modelo real.

Função de montagem `montar_apontamentos(dados: dict) -> list[dict]`, em duas passadas (D-07 exige numeração resolvida antes do texto):
- Passada A — seleção e numeração: percorre `ORDEM_PECAS`; para cada peça, coleta os itens cujo `documento` é a peça e cuja `classificação` está em `CLASSIFICACOES_CORPO`, **preservando a ordem de aparição no array `itens`** (Claude's Discretion do CONTEXT: ordem do documento analisado, não por severidade). Peça sem item não gera seção (D-05). Numera as seções sequencialmente a partir de 1 e as alíneas com `_letra`. Registra, num dicionário `primeira_ocorrencia[chave] = (numero_secao, letra)`, a primeira alínea de cada `_chave_equivalencia`.
- Passada B — texto: para cada alínea, se `_chave_equivalencia` já tem `primeira_ocorrencia` apontando para uma alínea **anterior** (número de seção menor, ou mesma seção com letra anterior), o texto vira `_texto_referencia_cruzada`; caso contrário, `_texto_alinea`.
- Seção de pendências (D-04): depois de todas as seções de peça, se houver ao menos um item com `classificação == "pendente"`, acrescenta uma seção com o próximo número e título `TITULO_PENDENCIAS`, cujas alíneas usam `_texto_alinea` (sem referência cruzada — pendência de documento ausente não se cruza com apontamento de peça). Ordem: ordem de aparição no array `itens`.
- Retorno: lista de dicts `{"numero": int, "titulo": str, "alineas": [{"letra": str, "texto": str}]}`.

Função pública `build_corpo_despacho_xml(dados: dict) -> str`:
- Chama `montar_apontamentos`; se a lista vier vazia, devolve `_paragrafo(ESTILO_ALINEA, TEXTO_SEM_APONTAMENTOS)` — o placeholder nunca fica vazio nem sobra `{{`.

- Não insere quebra de linha nem espaço entre os `<w:p>`; a string devolvida começa com `<w:p` e termina com `</w:p>`.

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| `dados_consolidados.json` → builder | **Entrada não confiável**: `parecer`, `fundamento`, `seção`, `de` são texto produzido por LLM a partir de PDF fornecido pelo usuário |
| builder → placeholder raw do DOCX (Plano 04) | O retorno do builder é injetado **sem escape** no `word/document.xml`; é o único caminho de XML cru do sistema |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-06-02-01 | Tampering | `_paragrafo()` — injeção de XML em `word/document.xml` via `parecer`/`fundamento`/`seção` | mitigate | Todo texto passa por `xml.sax.saxutils.escape`; `_paragrafo` é o único emissor de texto do módulo; `TestSegurancaXml` prova com payloads `</w:t>`, `&`, `]]>`, `<script>` |
| T-06-02-02 | Tampering | `w:pStyle` — injeção via nome de estilo | mitigate | `estilo` só recebe as constantes `ESTILO_PECA`/`ESTILO_ALINEA` do módulo; nunca deriva de dado do JSON |
| T-06-02-03 | Denial of Service | Dataset com milhares de itens, ou `parecer` gigante | accept | CLI offline, arquivo local, sem exposição de rede; custo é linear no número de itens |
| T-06-02-04 | Information Disclosure | Vazamento de item `conforme` ou do campo `para` para o despacho | mitigate | Filtro por `CLASSIFICACOES_CORPO`; proibição explícita de ler `para`, verificada por `grep -n '"para"'` no critério de aceite |
| T-06-02-05 | Spoofing | Referência cruzada apontando para alínea errada, distorcendo o documento oficial | mitigate | Numeração resolvida em passada A antes do texto (D-07); `test_referencia_aponta_para_a_letra_correta` fixa o comportamento |
| T-06-02-SC | Tampering | npm/pip/cargo installs | mitigate | Nenhuma dependência nova (`re`, `unicodedata`, `xml.sax.saxutils` são stdlib); `pyproject.toml` muda só a lista `packages`. Se um install for necessário, parar e abrir checkpoint humano bloqueante |
