<objective>
Tornar `sysdoc` e `sysdoc_dvi` chamáveis como biblioteca pela camada web, sem `subprocess` da CLI e sem reimplementar pipeline (D-03).

Hoje três funções são inutilizáveis por um chamador programático: `create()` devolve `int` e só imprime o caminho do DOCX; não existe função que localize o HTML gerado por `render()`; e `executar_run()` reporta progresso apenas por `print`. Este plano faz a refatoração mínima que resolve os três casos **preservando byte a byte a saída da CLI atual**.

Purpose: sem isto, os planos 07-03/07-06/07-07 não têm como saber o que foi gerado nem como mostrar progresso.
Output: `criar_documento()`, `localizar_html_analise()`, `sysdoc_dvi/progresso.py` e o parâmetro `progresso=` em `executar_run()`.
</objective>
