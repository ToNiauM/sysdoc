Criar `sysdoc_web/processos/uploads.py` com a lógica de recusa, isolada de Django forms para poder ser testada em unidade:
- `EXTENSOES_PERMITIDAS = frozenset(sysdoc.SUPPORTED_REFERENCE_SUFFIXES)` — importado, nunca redigitado, para que a web nunca aceite algo que o `prepare` não sabe extrair.
- `ASSINATURAS = {".pdf": b"%PDF-", ".docx": b"PK\\x03\\x04"}` — os dois formatos binários têm assinatura verificável; `.txt` e `.md` são verificados por decodificação UTF-8 (com `errors="strict"` sobre os primeiros 4096 bytes, aceitando também `latin-1` como fallback explícito).
- `class ArquivoRecusado(ValidationError)` — sempre com mensagem em português voltada ao pregoeiro, sem termo técnico.
- `def nome_seguro(nome_original: str) -> str`: separa `Path(nome_original).suffix.lower()`; recusa se o sufixo não estiver em `EXTENSOES_PERMITIDAS`; aplica `sysdoc.sanitize_filename` sobre o `stem`, trunca em 80 caracteres, e reanexa o sufixo validado. O resultado **nunca** contém `/`, `\`, `..` nem começa por ponto. Recusa nome que resulte vazio.
- `def validar_arquivo(arquivo) -> None`: verifica, nesta ordem, (1) extensão via `nome_seguro`; (2) `arquivo.size <= settings.SYSDOC_WEB_MAX_UPLOAD_MB * 1024 * 1024`, senão recusa com a mensagem que cita o limite em MB; (3) assinatura: lê os primeiros bytes com `arquivo.read(8)` e faz `arquivo.seek(0)`, comparando com `ASSINATURAS` para `.pdf`/`.docx` e tentando decodificar para `.txt`/`.md`; (4) para `.docx`, abre com `zipfile.ZipFile` sobre o objeto de arquivo, aplica a mesma checagem de entradas do `sysdoc._assert_safe_zip_entries` (recusa entrada absoluta ou com `..`), exige a presença de `word/document.xml`, e recusa se a soma dos `file_size` do `infolist()` exceder 200 vezes o tamanho comprimido (defesa contra zip bomb), sempre com `seek(0)` ao final.
- `def validar_conjunto(arquivos, maximo) -> None`: recusa lista vazia; recusa mais de `maximo` arquivos; recusa nomes duplicados após `nome_seguro`.
- `def gravar_em(diretorio: Path, arquivo) -> Path`: grava por `chunks()`, num caminho montado como `diretorio / nome_seguro(arquivo.name)`, e confirma `destino.resolve().parent == diretorio.resolve()` antes de abrir para escrita.
