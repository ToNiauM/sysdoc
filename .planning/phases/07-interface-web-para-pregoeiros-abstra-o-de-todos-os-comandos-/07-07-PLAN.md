<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| `dados_consolidados.json` → página HTML | O JSON é produto de um modelo de linguagem; seu texto é conteúdo não confiável |
| formulário de revisão → `.sysdoc/config.yaml` | Texto do usuário é gravado em arquivo de configuração lido pela CLI |
| formulário de revisão → DOCX | Os mesmos campos entram no `word/document.xml` do despacho |
| requisição de download → sistema de arquivos | Slug controlado pelo usuário resolve um arquivo servido |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-07-07-01 | Cross-site Scripting (Tampering) | `resultado.html` | mitigate | Auto-escape padrão do Django; `\|safe`, `{% autoescape off %}` e `mark_safe` proibidos por gate de grep; teste 3 injeta `<img src=x onerror=...>` no `parecer` e exige a forma escapada |
| T-07-07-02 | Cross-site Scripting (Tampering) | HTML da análise servido | mitigate | Servido apenas como `attachment`, com `X-Content-Type-Options: nosniff`, `Content-Security-Policy: sandbox` e `Referrer-Policy: no-referrer` — o HTML derivado de modelo nunca é renderizado na origem autenticada |
